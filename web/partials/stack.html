Built on AWS, end to end

Every number on this site comes from this pipeline. The code is open, so any city can run it on its own data.

  • Amazon Location Service · MapsThe dark basemap under every view.
  • Amazon Location Service · PlacesFound the published opening hours of {{nyc:hoursSources.places|int}} venues that host an AED, and turns addresses into points for your own data.
  • Amazon Location Service · RoutesA two-minute walking area for every one of {{nyc:findings.locations|int}} AED locations, plus walking times and routes when you drop a pin.
  • Registry of Open Data on AWSOverture Maps places: {{nyc:relocation.staffedBuildings|int}} fire stations, police stations and hospitals that could host a 24/7 cabinet.
  • Apache Iceberg tables on Amazon S3A nightly snapshot of New York's AED registry. Iceberg keeps every version, so the site can show what changed.
  • Amazon Athena + AWS Glue Data CatalogWrites the Iceberg snapshots, and queries Overture Maps where it sits on the Registry of Open Data.
  • Amazon BedrockEstimates hours where nothing is published, graded blind against known hours, and runs the two-sided debate.
  • Amazon API GatewayThe public API, with self-serve keys, usage plans and throttling.
  • AWS LambdaThe API, the MCP server for AI assistants, and the nightly refresh.
  • Amazon EventBridge SchedulerStarts the refresh every night.
  • Amazon DynamoDBCaps how many keys and AI debates can be created each day.
  • Amazon CloudFront + Amazon S3Serves this site and its open data downloads.
  • AWS CDKThe whole stack in one deployable app.
